A deterministic, single-clock composition that prepends trace analysis to Animation 15.

## Chapters and defaults

- 0.40–3.29s: a normal-size blue Bash agent using Animation 13's final loader enters, opens an owned trace report, and descends.
- 3.45–5.45s: the view resolves around the exactly centered `(640, 360)` agent into the 18×12 Issue grid.
- 5.25–7.50s: a gray analysis radius grows behind the grid; warnings appear by distance, and the center agent scales away.
- 7.50s onward: `sampleMicro15` and `Micro15Scene` render the established gather, covers, coding-agent window, and subtitles. Animation 20 uses an instantaneous owned appearance track so the radial endpoint equals the dispersed handoff.

The synthetic center hero temporarily suppresses cell 98's dot because the even-column source grid has no literal center cell. That exact source dot is restored while the hero scales out, before the handoff.

All storage IDs begin with `micro-animation-20-`; the prelude/handoff and native issue-detail timelines persist separately, and no Animation 15 migration module is imported. The handoff is editable while issue clips stay in native seconds; appearance remains intentionally locked instant and is not exposed as an inert control. `?time=<seconds>` is a paused, finite, nonnegative pure sample. The stage is authored at 1280×720 and uniformly scaled; toolbar and timeline clearance remain outside it.
