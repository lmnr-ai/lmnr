# Underscore Identity Studio

A browser prototype for choosing recurring musical DNA and a voiceover-safe sound world for the Laminar launch film.

## Run

From the repository root:

```bash
python3 -m http.server 4177
```

Open <http://localhost:4177/song-studio/>.

## What to compare

1. Filter between the new broad set, folk/traditional material, early jazz, and the earlier classical archive.
2. Choose a sourced melody and listen to its smallest reusable DNA cell.
3. Select one of six fixed treatments: Felt Piano, Digital Pings, Chamber Strings, Hybrid Score, Signal Bloom, or Paper Pulse.
4. Compare four audition modes:
   - **DNA only** isolates memorability.
   - **Under voiceover** keeps harmony running but allows melody only at authored returns.
   - **Full phrase** demonstrates why continuous melody can compete with narration.
   - **Ending check** auditions a planned cadence.

The mixer, detailed synthesis controls, saved mixes, and JSON export were intentionally removed. This prototype answers a narrower question: **which melodic identity and sound world should the finished underscore use?**
